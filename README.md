# VK to Telegram Post Aggregator Bot 🤖🚀

Полностью автономный скрипт на Python для автоматического дублирования и агрегации постов из нескольких сообществ ВКонтакте в один Telegram-канал. 

Проект оптимизирован для работы на бесплатных хостинг-платформах (например, **Render**) и снабжен механизмами защиты от «засыпания» сервера, умным обходом лимитов Telegram на медиафайлы и продвинутой фильтрацией контента.

---

## ✨ Основные возможности

* 📂 **Мульти-мониторинг:** Отслеживание неограниченного количества групп ВК одновременно (настраивается через простой словарь в коде).
* 🖼 **Умное удержание медиа:** Автоматический обход лимита Telegram на длину подписи к фото (1024 символа). Если пост длинный, фото незаметно встраивается в тело сообщения, жестко оставаясь **наверху поста**.
* 🔗 **Инлайн-кнопки:** Вместо громоздких ссылок в тексте, под каждым постом генерируется аккуратная кнопка-ссылка `🔗 Оригинал поста`.
* 🛠 **Исправление разметки ВК:** Встроенный парсер на регулярных выражениях (`re`) находит внутренние ссылки ВК и специфические теги вида `[#alias|текст|ссылка]`, превращая их в валидные и кликабельные HTML-ссылки для Telegram.
* 🛡 **Безопасность (100% Секьюрность):** Все конфиденциальные данные (токены, приватные ID каналов) полностью вынесены в переменные окружения (`.env` / Environment Variables) и не попадают в публичный код.
* 🔄 **Синхронизация профиля:** При запуске скрипт автоматически скачивает актуальную аватарку выбранного сообщества и устанавливает её на аватарку Telegram-канала.
* ⚡ **Анти-сон для хостинга:** Интегрированный микро-веб-сервер на **Flask**, работающий в отдельном фоновом потоке, позволяет бесплатно держать бота активным 24/7 с помощью внешних пинг-сервисов (UptimeRobot / Better Stack).

## 🚀 Локальное развертывание

### 1. Клонирование репозитория
```bash
git clone [https://github.com/твой_юзернейм/название_репозитория.git](https://github.com/твой_юзернейм/название_репозитория.git)
cd название_репозитория
```

### 2. Настройка виртуального окружения
Создайте и активируйте изолированное виртуальное окружение:

* **Windows:**
  ```bash
  python -m venv venv
  .\venv\Scripts\activate
  ```
* **macOS / Linux:**
  ```bash
  python -m venv venv
  source venv/bin/activate
  ```

### 3. Установка dependencies (зависимостей)
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте в корневой папке проекта файл **`.env`** и заполните его вашими данными:

```env
TG_TOKEN=
TG_CHANNEL=
VK_TOKEN=
```

> ⚠️ **Важно:** Файл `.env` содержит ваши личные доступы. Он автоматически добавлен в `.gitignore` и никогда не должен попадать в публичный репозиторий GitHub!

### 5. Запуск бота локально
```bash
python main.py
```

## ⚙️ Добавление новых групп для отслеживания

Чтобы добавить или удалить отслеживаемые сообщества, откройте файл `main.py` и отредактируйте словарь `VK_GROUPS` в блоке настроек:

```python
VK_GROUPS = {
    226921338: "Второй курс ИОТ, УрФУ",
    188533997: "Проектный практикум ИРИТ-РТФ",
    230634931: "Поселение ИРИТ-РТФ УрФУ",
    # Формат: ID_ГРУППЫ: "Отображаемое название в Telegram",
}
```

## ☁️ Деплой на хостинг (на примере Render.com)

Скрипт полностью готов к бесплатному развертыванию на платформе **Render** в качестве **Web Service**:

1. Создайте новый **Web Service** на Render и подключите этот репозиторий GitHub.
2. Укажите следующие параметры сборки:
   * **Runtime:** `Python`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
3. В разделе **Environment Variables** (Переменные окружения) добавьте три ключа из вашего файла `.env`: `TG_TOKEN`, `TG_CHANNEL` и `VK_TOKEN`.
4. Нажмите **Create Web Service**.
5. После успешного деплоя скопируйте выданный URL вашего приложения (например, `https://your-app.onrender.com`) и добавьте его в любой бесплатный пинг-сервис (**Better Stack** или **UptimeRobot**) с интервалом проверки 5 минут, чтобы бот никогда не уходил в спящий режим.

## 📝 Логирование проекта

* Статус проверки стен ВК.
* Логи успешной синхронизации аватарки.
* HTTP-ответы от Telegram API при отправке постов.
* Перехват и автоматическая фильтрация рекламных/системных объектов ВК, не имеющих валидного `post_id`.
